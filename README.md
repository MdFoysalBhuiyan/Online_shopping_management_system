Role Based E-Commerce Management System

An Online Shopping Management System built with PHP. This project provides a simple e-commerce platform for managing products and handling basic online shopping operations.

Features
🛍️ Browse available products
📦 Product management
🛒 Online shopping functionality
👤 User/customer management
🔐 Login and authentication
🗂️ Organized MVC-style structure
🖼️ Media and product image support
💻 Simple and user-friendly interface
Technologies Used
PHP
HTML
CSS
MySQL
MVC Architecture
Project Structure
Online_shopping_management_system/
│
├── controller/      # Application controllers
├── model/           # Database and application models
├── view/            # User interface files
├── media/           # Images and media files
├── index.php        # Main entry point

└── README.md        # Project documentation

Installation
1. Clone the Repository
git clone https://github.com/MdFoysalBhuiyan/Online_shopping_management_system.git

2. Move the Project

If you are using XAMPP, move the project folder into:

xampp/htdocs/

3. Configure the Database
Create a MySQL database using phpMyAdmin.
Import the project's database file if one is provided.
Update the database connection settings in the project according to your local MySQL configuration.
4. Start the Server

Start Apache and MySQL from XAMPP.

Then open:

http://localhost/Online_shopping_management_system/

Usage

After starting the project, users can access the online shopping system through their browser and interact with the available products and shopping features.

Purpose

This project was developed as an online shopping management system to demonstrate web application development using PHP, database integration, and an MVC-style project structure.
